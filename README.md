### 💡 프로젝트 개요

ParQ는 `Park (주차장)`과 `Queue (줄서기)`의 합성어로,  
주차를 위해 기다리는 불필요한 시간을 혁신적으로 단축시키기 위한 AI 기반 스마트 주차 정보 시스템입니다.

도시 내 주차 공간 부족, 기존 앱의 제한적인 정보 제공, 실시간 주차 정보 부재 등의 문제를 해결하여  
운전자에게 최적의 주차 경험을 제공합니다.

---

### 🎯 핵심 목표

- **주차 탐색 시간 단축**  
  직관적인 UI로 빠른 주차 공간 확인을 통해 불필요한 주행 시간을 최소화합니다.

- **불법 주정차 감소**  
  적절한 주차 공간 안내를 통해 불법 주정차 문제를 완화합니다.

- **탄소 배출량 감축**  
  불필요한 주행 감소를 통해 환경 친화적인 도시를 만드는데 기여합니다.

---

### 🌟 주요 기능

ParQ는 다음과 같은 혁신적인 기능으로 최고의 편의성을 제공합니다.

- **실시간 잔여 주차면수 제공**  
  주차장에 남은 자리 수를 실시간으로 정확하게 표시하여 즉시 확인이 가능합니다.

- **AI 기반 혼잡도 예측**  
  과거 요일 및 시간대별 입출차 이력을 분석해 주차장의 혼잡도를 예측(혼잡/보통/여유)하여 제공합니다.

- **실시간 CCTV 영상 제공**  
  주차장 내부 상황을 CCTV 영상으로 실시간 확인하여 정보의 신뢰성을 극대화합니다.

- **내비게이션 연동**  
  선택한 주차장으로 최적 경로 안내를 제공하여 헤매는 시간을 줄여줍니다.

- **개인화 서비스**  
  회원가입을 통한 사용자 인증 및 개인화된 주차 정보를 제공합니다.

- **다국어 지원**  
  한글과 영어 등 다국어 지원으로 사용자 접근성을 높였습니다.

- **고객 센터**  
  1:1 문의 및 답변 기능으로 사용자와 소통을 강화합니다.

### 🛠️ 기술 스택

#### 🌐 시스템 아키텍처

ParQ는 안정적이고 효율적인 서비스 제공을 위해 체계적인 아키텍처 기반으로 설계되었습니다.  
(시스템 아키텍처 다이어그램은 추후 추가 예정입니다.)

#### 🧠 AI/ML 모델링

- **주차장 빈 자리 탐색**: YOLOv8m (You Only Look Once v8 medium)  
  - 학습 데이터: 직접 크롤링 및 라벨링한 509개 이미지 데이터셋 사용  
  - 평가 지표: mAP50: 0.8719, mAP50-95: 0.5062, Precision: 0.8425, Recall: 0.8015

- **주차장 혼잡도 예측**: LSTM (Long Short-Term Memory)  
  - 학습 데이터: 울산시설공단, 한국체육산업개발주식회사 등 공공기관 입출차 데이터 활용  
  - 주요 특징: 입차, 출차, 시간 sin/cos, 요일 sin/cos 등 6가지 변수 사용  
  - 평가 지표: MAE: 25.77, MSE: 3859.86, RMSE: 62.13, R²: 0.4258

#### 💻 백엔드

- 언어 및 프레임워크: Java, Spring Boot  
- 데이터베이스: MySQL  
- API: FastAPI (모델 서버), Spring Boot (서비스 서버) 기반 RESTful API 설계 및 구현  
- 주요 기능: DB 연동, 동영상 업로드/다운로드, 주차장/혼잡도/CCTV/게시판 API 등

#### 📱 프론트엔드 (모바일 앱)

- 플랫폼: Android (Kotlin, XML)  
- 주요 라이브러리: Retrofit, OkHttp (서버 API 연동), Google Maps API (지도 및 위치 안내), VideoView (CCTV 스트리밍), Glide (이미지 로딩)  
- 주요 기능: 실시간 주차장 및 혼잡도 정보, CCTV 영상 스트리밍, 지도 기반 위치 및 경로 안내, 1:1 고객센터, 즐겨찾기, 다국어 및 접근성 지원
